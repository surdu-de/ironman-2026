## Three-Track Focus

### Track 1: Raise FTP (240W → 255-265W)

- Sustained sweet spot 2x/week (12-20min blocks @ 90-94% FTP)
- Threshold intervals 1x/week (3x10min @ 95-100% FTP)
- **Clean FTP test in Wk26 mid-week** (Wed) - first real test in 3 cycles
- Indoor for structured intervals (need power), outdoor for endurance + race rehearsal

### Track 2: Body Weight (89 → 86-86.5 kg, revised May 5)

- Now at **87 kg** (May 18, Wk28 Mon), -2kg from cycle start, -1kg from Wk26 check
- Moderate deficit ~500-600 kcal/day on non-key days (Wed/Fri/Mon)
- **Full fuel** on Sat long ride, Thu intervals, Tue threshold
- No deficit in taper (Wk29-30)
- Levers: cut alcohol, reduce evening carbs on rest/easy days, full carb pre/during/post key sessions
- Target: 0.4-0.6 kg/week → land at **86-86.5 kg by end Wk28**, hold through taper. (Original 85kg target dropped, too aggressive given cast period and need to protect training quality.)

### Track 3: Race Nutrition Execution

- **Wk26 long ride = full race-day rehearsal** (test exact products + flavors)
- 80-90g carbs/hour from minute 30
- 600-800ml/hour fluid + 500-1000mg sodium
- Brick run nutrition transition practiced Wk26-27
- **No new products in last 4 weeks** before race

## Behavioral Guardrails (carrying forward from Cycle 6 failures)

1. 2. **Brick run is non-negotiable** every weekend Wk26-28. Indoor counts. Don't skip like after the 220km in Cycle 6.
2. **Sleep gates progression** - if morning HRV / sleep is bad, swap hard for easy.
3. **No new nutrition products** in Wk29-30.
4. **Recovery happens in taper** - if Wk26-28 push starts to break the body, drop a hard day, don't muscle through.
5. **Cast protection (May 5-19)**: no swim, no outdoor bike. Trainer only. If wrist pain spikes during/after a session, stop and reassess, losing race day to re-injury is worse than skipping a workout.
6. **Friday is "easy by feel"**, replaces rest. HR <140 run or Z1-Z2 spin. Never let it drift into tempo before Sat long ride.
